## 1. 제품 목표와 핵심 경험

FOLIO는 강의 PDF를 태블릿에서 보면서 AI 설명과 확인문제를 짧은 단위로 학습하는 서비스입니다. 필요 시 강의 녹음과 PDF를 결합하여 설명 품질을 개선하는 방향을 계획하지만, **현재 GitHub의 시안에 실제 AI·녹음 분석 기능이 연결된 것은 아닙니다.**

- **핵심 사용자 경험:** PDF의 2~3페이지 정도를 학습 → 핵심 설명 확인 → 3~4문항 정도로 즉시 이해도 점검 → 다음 단위로 이동.
- **우선 기기:** iPad 및 Galaxy Tab. **태블릿 가로모드**를 최우선으로 하되 세로모드·휴대폰에서도 조작 가능해야 합니다.
- **공부 화면:** 화면 바깥의 쓸모없는 여백을 줄이고 PDF의 가독성과 실제 학습 기능에 공간을 배분합니다.
- **가로 화면:** 좌측·우측 패널 각각에서 **PDF / AI 설명 / 확인문제** 중 독립 선택, 분할 비율 조절.
- **태블릿 세로:** 위·아래 패널 배치. **휴대폰:** 탭 전환형 단일 패널.
- 학습을 방해하는 불필요한 안내·장식·아이콘을 추가하지 않습니다. UI는 의도적으로 정보 밀도와 조작의 명확성을 우선합니다.

## 2. 승인된 디자인 기준선

- **Dark Workspace v1.2**가 기존 승인 디자인의 기준입니다. 차콜·딥 네이비 계열의 차분한 다크 UI와 간결한 한국어 타이포그래피를 유지합니다.

- 사용자가 승인한 기존 화면을 전면 재설계하지 않습니다. 디자인 개선은 **한 번에 한 문제를 최소 범위로** 다루고, 실제 확인된 문제를 근거로 제안합니다.
