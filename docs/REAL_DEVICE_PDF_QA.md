## 1. 검사 전 준비

- **대상 기기:** (A) iPhone + Safari, (B) iPad + Safari(세로/가로), (C) Galaxy Tab + Samsung Internet(세로/가로). 외부 키보드가 있는 기기에서만 키보드 항목을 수행하고 미연결이면 N/A로 남깁니다.
- **방문 주소:** 공개 Pages URL 사용 금지. 필요 시 개발 PC의 **신뢰 가능한 폐쇄형 로컬 네트워크**에서 정적 `index.html` 및 `styles/`을 임시 서빙합니다. 기기에서 HTTP 주소 접속 전 PC 방화벽/공유기 접근 범위를 확인합니다. Wi-Fi에 연결된 다른 사용자가 접근할 수 있는 환경은 피합니다. 실기기 접속 방법이 불확실하면 해당 항목 NOT RUN 유지.
- **검사 파일:** 개인정보·저작권 제약이 없는 **합성 PDF**를 기기에 미리 저장합니다. 테스트용 파일은 최소 3쪽, 한국어 텍스트, 컬러 도형, 가로로 긴 도표, 수식, 여러 페이지 레이아웃을 포함합니다. 파일명은 단순 영문, 크기는 20MB 이내.
- **개인정보:** 실강의/실사용 PDF를 선택하거나 GitHub Actions·이메일·공개 저장소로 전송하지 않습니다. 스크린샷은 합성 콘텐츠만 포함하고 네트워크/파일 경로/개인 식별정보를 노출하지 않습니다.
- **버전 기록:** 기기 모델/OS/브라우저 버전, 네트워크 경로, 브랜치 및 정확한 PR HEAD SHA, 검사 일시(Asia/Seoul), 테스트 파일 페이지 수·크기(내용 제외).

## 5. 자동화되는 파일 교체·키보드 경계조건 (2026-11-12)

- **자동 QA 대상:** `application/pdf`·`.pdf`라는 이름만 가진 잘못된 합성 파일, 0바이트 파일, 올바른 PDF를 연속 선택합니다. 앞선 정상 PDF의 `blob:` URL·현재 쪽·확대율이 불량 파일 때문에 교체/해제되지 않아야 합니다.
- **정상 교체 시 기대 동작:** 새 합성 PDF를 기기에서 `blob:` URL로 열고 1쪽·100%로 초기화합니다. 새 뷰어가 생성된 후 기존 object URL은 1회 해제됩니다. 외부 네트워크 전송은 하지 않습니다.
- **키보드 파일 선택기:** PDF 파일 열기 버튼에 초점을 주고 Enter로 파일 선택기를 호출한 후 정상 PDF를 선택하면, 새 DOM에 다시 나타난 파일 열기 버튼으로 포커스가 돌아오는지 Chromium·WebKit에서 검사합니다.
- **범위 주의:** 로컬 헤더의 `%PDF-` 문자열 확인은 형식 오류를 일부 걸러내는 **간단한 사전검사**일 뿐, PDF의 전체 무결성·암호·악성 파일 여부를 판별하지 않습니다. 브라우저 내장 PDF 렌더링은 실기기 테스트가 필요합니다.
- **실기기 결과:** 위 모든 실제 iPhone/iPad/Galaxy Tab 테스트는 여전히 **NOT RUN**입니다. Playwright 성공을 실기기 통과로 해석하지 않습니다.

## 6. 파일 선택 취소·경합 QA (2026-11-12)

- **선택 취소:** 파일 열기 버튼에서 선택기를 열고 취소하면 기존 문서·현재 페이지·확대율·`blob:` URL을 변경하지 않고, 파일 열기 버튼으로 키보드 초점을 돌립니다. Playwright는 실제 OS의 '취소' 버튼을 누르지 못하므로 `cancel` 이벤트를 **합성 발생**시켜 앱 처리 경로만 검증합니다. 브라우저/기기 선택기의 실제 취소 동작은 여전히 **NOT RUN**입니다.
- **동일 파일 재선택:** 선택기 호출 전에 숨겨진 file-input 값을 비워, 유효하지 않은 파일을 선택했다가 **동일한 파일을 다시 선택**할 때도 `change` 이벤트와 검증이 다시 실행되도록 합니다.
- **비동기 선택 역전:** 첫 PDF의 로컬 헤더 읽기가 지연되는 동안 두 번째 PDF를 선택해도 첫 번째의 뒤늦은 응답으로 문서·URL·페이지가 덮어써지지 않아야 합니다. 선택 순서 토큰으로 이전 비동기 검사를 무효화합니다.
- **객체 URL:** 취소/잘못된 파일/무효화된 읽기에서는 새 object URL을 만들거나 기존 URL을 해제하지 않습니다. 유효한 새 PDF만 성공적으로 반영할 때 기존 로컬 URL을 해제합니다.
- **개인정보 및 파일 전송:** 합성 PDF만 사용하여 외부 HTTP(S) 요청 0건을 확인합니다. 사용자의 실제 PDF 업로드 금지, 실기기 iPhone·iPad·Galaxy Tab 및 VoiceOver/TalkBack **NOT RUN**, W01/W02 동결·W03 미승인.
